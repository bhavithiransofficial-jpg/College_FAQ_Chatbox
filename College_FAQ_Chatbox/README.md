# College FAQ Chatbot

## Placements & Careers

A web-based College FAQ Chatbot developed using Python, Flask and Natural Language Processing.

The chatbot answers frequently asked questions related to:

- Placement process
- Placement eligibility
- Aptitude tests
- Technical interviews
- HR interviews
- Resume preparation
- Internships
- Career preparation
- Placement registration

## Technologies Used

- Python
- Flask
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- HTML
- CSS
- JavaScript

## Project Architecture

User Question
↓
Flask Web Application
↓
TF-IDF Vectorization
↓
Cosine Similarity
↓
FAQ Matching
↓
Answer Generation
↓
Chatbot Response

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Open the project:

cd College_FAQ_Chatbox

Create a virtual environment:

python -m venv venv

Activate the environment on Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Open the browser:

http://127.0.0.1:5000

## Features

- NLP-based FAQ matching
- TF-IDF text vectorization
- Cosine similarity
- Confidence threshold
- Fallback response
- Quick question buttons
- Responsive web interface
- No external API required
